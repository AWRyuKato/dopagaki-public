## お問い合わせ

不具合の際は、iOS／Androidの種類、アプリのバージョン、問題が起きた画面、再現する手順を分かる範囲でお知らせください。

**投稿は公開されます。** 氏名、メールアドレス、購入レシート、端末識別子、セーブデータなどの個人情報・機密情報は投稿しないでください。画像を添える場合も、個人情報が写っていないことを確認してください。

投稿にはGitHubアカウントが必要です。ゲームのプレイやこの資料の閲覧にアカウントは必要ありません。

このページの公開は、アプリのストア公開完了を意味しません。
